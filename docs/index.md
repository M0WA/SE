# searchengine docs

A self-hosted AI chatbot with search-engine features, written in Go. Same
documentation as the repo's own [README](https://github.com/M0WA/SE) and
`docs/` folder, rendered as a real page instead of raw markdown.

## Start here

- **Installing, configuring, or using the admin UI?** [User manual](manual/) --
  every environment variable, config file, and admin settings page,
  screenshotted and explained field by field, plus the public search/chat page.
- **Understanding how it's built?** [Architecture](architecture/) -- the
  hexagonal-architecture layout, all eight binaries, and how they connect
  to external systems, with a diagram.

Source, issues, and every `packaging/*/README.md` live in the repo itself:
[github.com/M0WA/SE](https://github.com/M0WA/SE).
