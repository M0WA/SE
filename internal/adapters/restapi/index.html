Search syntax
word
matches pages containing it
+word
must appear
-word
must not appear
"exact phrase"
matches that phrase exactly
-"exact phrase"
that exact phrase must not appear
site:example.com
only that site (and its subdomains)
-site:example.com
excludes that site (and its subdomains)

Combine them freely — e.g. cats +shelter -kitten site:example.com. Add &top_k=N to the URL for more than the default number of results.
