Chat hooks

Each hook is offered to the chat model as a native tool-calling function -- the model decides whether and when to call it. When it does, a script runs with the model-supplied argument, and the result is fed back to the model for a real answer, shown separately as a folded aside. Requires the configured chat endpoint to support native tool-calling (e.g. vLLM launched with --enable-auto-tool-choice) -- see packaging/chat-hooks/README.md.
