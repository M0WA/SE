Chat hooks

A regex match against a chat answer runs a script with the matched text as its argument; the result is fed back to the model for a real answer, and shown separately as a folded aside. Needs a system prompt (Settings -> Chat) telling the model how to invoke a hook -- see packaging/chat-hooks/README.md.

Add hook

iA Go regexp with exactly one capture group -- that group's matched text is the only thing ever passed to the script, as an opaque argv value.
iA script filename only, never a path -- resolved against a fixed, admin-controlled script directory.
iThis hook's own static instructions, injected as a separate system message only while the hook is active (see "Gated by web search" below) -- in addition to the endpoint's own persistent system prompt (Settings -> Chat), not instead of it.
iWhen checked, this hook (and its Prompt) is only active when the chat's Web toggle is on -- the same Search the web setting (Settings -> Chat) or its per-question override, not a separate control. When unchecked, this hook is active whenever Enabled is checked, regardless of the Web toggle.
