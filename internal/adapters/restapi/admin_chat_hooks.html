Chat hooks

Regex triggers matched against every chat answer: whenever a hook's pattern matches, the matched capture group is passed as an argument to its script, and the script's output is fed straight back to the model for a real, results-informed final answer -- the model's own tool-call text is never shown to the user. The raw script output is still shown separately as a labeled, folded aside for transparency. A lightweight, deliberately narrow tool-calling mechanism -- not a general plugin system. Needs a system prompt (Settings -> Chat) that actually tells the model when and how to invoke a hook -- see packaging/chat-hooks/README.md for a suggested one.
