Overview Documents Crawl Schedules Tuning Search Overrides

Adjust ranking, crawling, and session behavior. Changes apply to every process (search, admin, crawl) within about 10 seconds.

Ranking




Defaults: alpha 0.5, k1 1.2, b 0.75. Values outside 0–1 (alpha, b) or below 0 (k1) are clamped.

Crawler







Defaults: 8s timeout, 20 pages, 50 characters minimum, 250ms delay, 5120 KB (5 MB) response cap.

Search



Defaults: 10 results, 200 candidates. Every BM25 match is always scored too; this only bounds how many additional documents get sampled for a purely semantic match.

Database connection pool




Defaults: 25 open, 25 idle, 5 minute lifetime. SQLite always keeps a single connection regardless of these values, since it serializes writers at the file level; a running process re-reads and re-applies these within about 10 seconds of a save, but the effect on already-open connections is limited to pool bookkeeping (idle/lifetime), not an instant reconnect.

Session


Default: 12 hours. Applies to sessions created after saving.
