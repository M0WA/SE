Semantic search's vector space: the built-in hash provider plus any number of configured HTTP embedding endpoints, which one(s) are enabled, and which one is active for search. The hash toggle and active-for-search choice are configured on Settings; each HTTP endpoint's own base URL/model/key/dimensions/rate limit is managed on HTTP endpoints.

Recompute embeddings

Re-embeds every document's already-stored text against every currently-enabled provider -- no re-crawl needed, since the indexed text itself doesn't change. Necessary after enabling a provider or changing its model/dimensions on Settings; switching which already-enabled provider is active for search never needs this, since both are kept warm on every crawl.
